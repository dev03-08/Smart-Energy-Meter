# Smart-Energy-Meter
Smart Energy Meter is an IoT-based energy monitoring system designed to measure and monitor electricity consumption in real time. Built using the ESP32 microcontroller, the system utilizes the ACS712 current sensor to measure electrical current, calculates power and energy consumption, displays live readings on a 16×2 I2C LCD, and sends the data to the Blynk IoT platform for remote monitoring.

The project provides users with an intuitive way to track energy usage, helping promote efficient power management and reduce unnecessary energy wastage. By combining embedded systems, IoT connectivity, and real-time data visualization, this project demonstrates a practical and scalable solution for smart home and educational applications.

✨ Features
📊 Real-time current, power, and energy monitoring
📱 Remote monitoring using the Blynk IoT platform
🖥️ Live data display on a 16×2 I2C LCD
⚡ Accurate current sensing using the ACS712 sensor
🌐 Wi-Fi connectivity through the ESP32
🔋 Low-cost and energy-efficient IoT solution
🏠 Suitable for smart home and educational applications
